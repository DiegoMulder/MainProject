# UI fonts

| File | Font | Used for | License |
| --- | --- | --- | --- |
| IMFellEnglishSC-Regular.ttf | IM Fell English SC, digitised by Igino Marini from the Fell types | Game title, major headings | SIL Open Font License 1.1 — `OFL-IMFellEnglishSC.txt` |
| EBGaramond-Variable.ttf | EB Garamond by Georg Duffner and Octavio Pardo | Subtitles, menu items, flavour text | SIL Open Font License 1.1 — `OFL-EBGaramond.txt` |
| Inter-Regular.ttf, Inter-SemiBold.ttf | Inter by Rasmus Andersson | Settings, lobby details, HUD, prompts (readability) | SIL Open Font License 1.1 (https://openfontlicense.org) |
| RobotoMono-Regular.ttf | Roboto Mono by Christian Robertson / Google | Lobby codes, counters, timers | Apache License 2.0 (https://www.apache.org/licenses/LICENSE-2.0) |

Inter and Roboto Mono were copied from the Unity App UI package (`com.unity.dt.app-ui`) already present in this project. IM Fell English SC and EB Garamond come from the Google Fonts repository (github.com/google/fonts, `ofl/`). Keep this file and the OFL texts with the fonts when distributing builds or source.
